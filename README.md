# Student Management System

A simple and user-friendly Student Management System developed using React.js. This application allows users to add, view, and delete student records through an interactive web interface.

## Live Demo

**Website:** https://student-app-task04.web.app

**Hosting Platform:** Firebase Hosting

## Features

- Home page with welcome message
- Student registration form
- Add new student details
- View student records in a table
- Delete student records
- Navigation between pages
- Shared student data using React Context API
- Simple and responsive user interface

## Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| JavaScript | Application logic |
| HTML5 | Page structure |
| CSS3 | Styling |
| React Router DOM v6 | Page navigation |
| React Context API | State management |
| Firebase Hosting | Website deployment |
| GitHub | Version control |

## Application Pages

### 1. Home Page
Displays a welcome message and provides navigation to other pages.

Route: `/`

### 2. Student Details
Displays student information in a table containing:

- Student ID
- Name
- Department
- Actions (Delete)

Route: `/students`

### 3. Application Form
Allows users to enter student information.
